技能将安装到当前钉钉用户的本地技能库。

        

        
      

      

        
        将技能文件、ZIP 或文件夹拖到这里

文件要求

        
    
          
  • 独立技能文件支持 .md、.markdown 和 .zip
    • 
          
  • 导入完整文件夹时请选择其中的 SKILL.md，文件夹资源会一并导入
    • 
          
  • Markdown 文件必须包含 YAML 格式的技能名称和描述
    • 
          
  • DOCX、PPTX、XLSX、PDF、图片、CSV、JSON、代码和模板可作为技能包内资源
    • 
          
  • 不限制单个文件和技能包大小；仅校验格式、路径安全和执行风险
