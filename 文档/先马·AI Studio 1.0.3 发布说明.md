# 先马·AI Studio 1.0.3 发布说明

## 版本信息

```text
显示版本：1.0.3
内部版本：1.0.3
更新通道：stable-v2
系统：Windows 10/11 64 位
```

## 本次新增

- 新增通用 Windows 应用发现、启动、切换和窗口识别。
- 新增 UI Automation 控件读取、点击、文字输入、文字读取和快捷键操作。
- 新增应用窗口截图、多模态画面理解和相对坐标操作。
- 标准控件支持 UIA、Win32 消息、键盘和鼠标多级后备。
- 截图支持屏幕复制和 `PrintWindow` 双通道。
- 任意应用任务使用动态路由，不限于预置软件名称。
- 发送消息使用一次性草稿和二次确认，草稿按钉钉用户与会话隔离。
- 危险应用操作接入统一确认弹窗和本地审计。

## 安全边界

- 所有登录用户默认可使用本机操作能力。
- 仅使用当前 Windows 账号已有权限，不绕过 ACL 或 UAC。
- 外发、提交、发布、删除、支付、安装、卸载和危险命令必须确认。
- 不实现后台远控、屏幕监控、键盘记录或无人值守控制。
- 不读取密码输入框，不保存消息正文、密码、令牌或浏览器 Cookie 到审计日志。

## 数据兼容

- AppId 保持 `com.xianma.ai-studio.desktop`。
- 用户数据路由和历史兼容逻辑保持不变。
- ProgramData 配置目录保持 `C:\ProgramData\XianmaAIStudio`。
- 更新通道保持 `stable-v2`。
- 覆盖更新不得删除历史对话、钉钉会话、技能和用户文件。

## 验证结果

- 源码语法、版本一致性和数据保留测试通过。
- 通用应用发现、截图、控件读取、中文输入、坐标输入和普通点击通过。
- 危险应用操作拒绝和审计记录通过。
- 对话、钉钉、文件、文档、附件、技能、网页和更新服务回归通过。
- 打包应用真实启动、流式模型对话、更新检查、HTML 生成和预览通过。

- 尚未在独立测试电脑执行真实卸载、安装和自动更新覆盖验收。
