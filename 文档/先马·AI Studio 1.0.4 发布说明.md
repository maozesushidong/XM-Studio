# 先马·AI Studio 1.0.4 发布说明

## 版本

```text
显示版本：1.0.4
内部版本：1.0.4
更新通道：stable-v2
平台：Windows x64
```

## 新增功能

- 新增公司技能创建向导和标准 ZIP 模板。
- 支持 Markdown、ZIP 和技能文件夹导入及修正。
- 支持技能分片后台上传、断点续传和进度通知。
- 新增我的提交、公司技能库和审核状态展示。
- 审核后台新增技能预览、批准、驳回、高风险确认和下架。
- 公司技能支持 SHA-256 与 Ed25519 签名校验。
- 已安装公司技能支持启动时及每 15 分钟自动更新。
- 下架技能会在同步时停用并隔离。
- 新增完全匿名的技能调用、成功、失败和取消统计。
- 修复生成文档下载时因同名文件被 Word 或其他程序占用而出现 `EBUSY` 的问题；短暂占用自动重试，持续占用自动另存新文件。
- 统一优化技能生成文档排版：自动移除 YAML、`#`、`**`、代码围栏等技术标记，并转换为正式标题、基本信息表、章节、列表和表格。
- Word 文档统一使用微软雅黑、清晰标题层级、规范行距和页边距；PPT、Excel、PDF、OpenDocument、RTF、HTML、TXT、Markdown、JSON、XML、CSV 和 ZIP 同步清理排版标记。

## 安全与隐私

- 技能包拒绝路径穿越、符号链接、损坏压缩包、压缩炸弹和明文密钥。
- 公司技能接口要求有效桌面会话和 MAPMS 权限。
- 统计不保存使用人、提示词、附件、结果、路径、设备和 IP。
- 高风险技能审核与运行时危险操作确认相互独立。

## 兼容性

- 保持原 AppId、用户数据路由和历史会话迁移逻辑。
- 保持钉钉登录、多用户隔离、本地技能、在线技能、对话、文件、文档和本机操作能力。
- 更新通道保持 `stable-v2`。

## 发布状态

本版本已完成本地构建和自动化回归，尚未上传服务器、尚未部署公司技能服务端、尚未发布自动更新。应先在独立测试电脑试用，再按手工部署说明发布。

## 已知事项

- 当前安装包未使用公司 Windows 代码签名证书，系统可能显示未知发布者。
- 公司技能服务端未部署前，公司技能相关页面会显示服务暂不可用。
- macOS 暂未包含在本版本中。
