# 先马·AI Studio 1.0.2 用户操作手册

## 一、手册信息

```text
软件名称：先马·AI Studio
适用版本：1.0.2
适用系统：Windows 10/11 64 位
安装方式：Windows EXE 安装包
```

安装文件：

```text
先马·AI Studio Setup 1.0.2 统一版本重装版.exe
```

> 当前安装包尚未进行正式 Windows 数字签名。首次运行时，Windows 可能显示“未知发布者”，请确认安装包来自公司内网或指定负责人后再继续。

## 二、从旧版升级到 1.0.2

本次需要先卸载旧版，再安装 1.0.2。按以下步骤操作不会主动删除历史对话和本地数据。

1. 正常退出先马·AI Studio。
2. 打开 Windows“设置”。
3. 进入“应用 → 已安装的应用”。
4. 找到旧版先马软件，点击“卸载”。
5. 卸载完成后，不要使用第三方强力卸载或清理工具。
6. 不要手动删除带有 `XianmaAIStudio`、`xianma-ai-studio` 或 `xianma-centaur-desktop` 名称的数据目录。
7. 双击新版安装包进行安装。
8. 安装完成后，用原来的钉钉账号登录并检查历史对话、技能和文件。

## 三、全新安装

1. 获取公司提供的 `先马·AI Studio Setup 1.0.2 统一版本重装版.exe`。
2. 双击安装包。
3. 出现 Windows 权限提示时点击“是”。
4. 保持默认安装目录，按界面提示继续。
5. 安装完成后启动先马·AI Studio。

默认安装位置：

```text
C:\Program Files\先马·AI Studio
```

如 Windows 阻止运行：

1. 确认文件名和来源正确。
2. 在安全提示中点击“更多信息”。
3. 点击“仍要运行”。
4. 不要运行来源不明或文件名被修改的安装包。

## 四、钉钉登录与退出

### 登录

1. 启动软件。
2. 点击“打开扫码登录”。
3. 使用手机钉钉扫描二维码。
4. 在手机钉钉中确认登录。
5. 登录成功后自动进入个人工作台。

勾选“下次自动进入工作台”后，登录状态有效时会自动进入。登录过期时需要重新扫码。

### 退出

1. 点击左下角“退出登录”。
2. 确认退出。
3. 软件返回钉钉登录页。

不同钉钉用户的会话、技能和应用私有文件相互隔离。退出登录不会删除该用户的本地历史数据。

## 五、界面说明

左侧主要入口：

- “新对话”：创建新的 AI 对话。
- “搜索”：搜索历史任务、技能和已安排内容。
- “提示词库”：打开提示词参考页面。
- “已安排”：自动化任务功能仍在开发中。
- “技能”：查看、安装和使用技能。
- “最近对话”：切换历史会话。
- “设置”：检查软件更新。
- “退出登录”：退出当前钉钉账号。

窗口右上角可以最小化、最大化或还原、关闭软件。

## 六、使用 AI 对话

### 发起对话

1. 点击左侧“新对话”。
2. 在底部输入框输入问题或任务。
3. 按 `Enter` 发送，按 `Shift + Enter` 换行。
4. 回复生成时可以继续切换到其他会话操作。
5. 需要停止当前回复时，点击输入区右侧的停止按钮。

示例：

```text
总结这段文字，并按“结论、问题、下一步”整理。
读取 D:\资料\销售数据.xlsx，生成本月分析报告。
在桌面生成一份项目周报 Word 文档。
生成一个俄罗斯方块网页，并直接打开预览。
```

### 切换模型

1. 点击输入框右下方的模型名称。
2. 从列表中选择需要的模型。
3. “自动选择”会根据任务类型自动选择合适模型。
4. 图片生成应选择 `gpt-image-2` 或使用“自动选择”。

模型选择只影响之后发送的请求。不同模型的响应速度和支持能力可能不同。

### 管理会话

- 点击“新对话”创建独立会话。
- 点击左侧历史会话切换内容。
- 可对会话重命名，便于后续查找。
- 可将重要会话置顶。
- 可删除不再需要的会话；删除后无法恢复。
- 多个会话可以同时处理任务，切换页面不会自动停止其他会话。

## 七、添加附件和粘贴内容

### 选择文件

1. 点击输入框左下方的“+”。
2. 点击“添加文件”。
3. 选择一个或多个文件。
4. 文件会显示在当前对话输入区中。
5. 输入处理要求并发送。

也可以把文件直接拖入软件，或在输入框中使用 `Ctrl + V` 粘贴剪贴板中的文字、图片或文件。

支持常见文档、表格、演示文稿、PDF、图片、压缩包、代码、视频、录音和音频。软件不设置产品级文件大小限制，但实际处理速度仍受电脑性能、磁盘空间、网络和模型能力影响。

### 附件使用建议

- 在问题中明确写出要处理哪个文件。
- 多个同名文件时写明绝对路径。
- 大文件处理期间不要移动、改名或删除源文件。
- 涉及隐私、合同、财务或客户资料时，发送前确认内容是否允许交给模型处理。

## 八、生成和处理文件

所有会话都可以进行文件和文档操作，不需要进入单独工作区。

支持：

- 创建和编辑 Word、PPT、Excel、PDF。
- 生成和处理图片。
- 创建代码、网页和常见文本文件。
- 读取、新建、修改、复制、移动、搜索和打开文件。
- 使用 `C:\`、`D:\` 等当前 Windows 账号有权限访问的路径。

建议在指令中写清楚：

```text
输出格式
保存目录或绝对路径
文件名称
是否允许覆盖同名文件
内容和排版要求
```

示例：

```text
根据附件生成 Word 会议纪要，保存到 D:\会议资料\会议纪要.docx，不要覆盖同名文件。
把 D:\数据\销售明细.xlsx 整理成图表，并生成 D:\数据\销售分析.pptx。
在 C:\Users\当前用户名\Desktop\俄罗斯方块 中生成网页并直接预览。
```

### 查看生成结果

- 生成文件会以文件卡形式显示在结果或对话中。
- 鼠标悬停可查看文件绝对路径。
- 点击文件卡可在应用内预览支持的格式。
- 点击“复制”可复制文件或结果内容。
- 点击“下载”可另存到自己选择的位置。
- HTML 网页可以直接打开应用内预览，不需要用户手动创建文件。

## 九、使用和安装技能

### 在当前对话选择技能

1. 打开需要使用技能的对话。
2. 点击输入框左下方的“+”。
3. 在“选择技能”中搜索并选择技能。
4. 技能标签只关联当前会话。
5. 输入具体任务并发送。
6. 不再使用时点击“清除技能”。

在“技能”页面点击“使用”会打开独立技能表单，不会给所有对话添加技能标签。

> 技能最好在对话中使用。部分在线技能受自身流程影响，需要多轮对话才能产生合适结果。

### 从本地安装技能

1. 进入“技能”。
2. 点击“从本地添加”。
3. 选择技能文件、ZIP 或技能文件夹。
4. 检查技能名称、来源和风险提示。
5. 点击“安装技能”。
6. 安装会在后台继续，可以切换到其他页面。
7. 安装完成后软件会显示通知。

支持的技能入口：

```text
.md
.markdown
.zip
包含 SKILL.md 的文件夹
```

技能包可以包含 DOCX、PPTX、XLSX、PDF、图片、CSV、JSON、代码和模板等资源。

### 安装在线技能

1. 进入“技能”。
2. 点击“在线技能库”。
3. 搜索技能，或粘贴可信的 GitHub 技能仓库地址。
4. 查看来源和风险提示。
5. 确认后安装。
6. 安装完成后在当前对话中选择使用。

仅安装来源可信的技能。包含脚本、命令或网络访问能力的技能可能触发安全确认。

## 十、本机操作与安全确认

AI 只能使用当前 Windows 账号本来就有的权限，不能绕过 Windows 文件权限或 UAC。

以下普通操作通常不会弹出确认：

- 查看目录和读取文件。
- 新建文件。
- 打开文件或网页。
- 生成应用内预览。

以下操作必须由用户二次确认：

```text
覆盖已有文件
删除文件或目录
移动或复制并替换已有文件
运行 Shell、PowerShell 或 CMD 命令
安装或卸载软件
修改注册表、服务、启动项或计划任务
上传文件、发送消息、发布内容或提交表单
```

确认弹窗会显示操作类型、目标路径和命令摘要。请先核对，再选择：

- “允许本次操作”：只执行弹窗展示的本次操作。
- “取消”：拒绝操作，文件和系统状态保持不变。

看不懂命令、路径不正确或操作超出预期时，直接点击“取消”。

## 十一、浏览器与网页任务

软件可以打开可见的自动化浏览器，完成打开网页、点击、输入、下载和网页预览。

- 默认使用独立浏览器环境，不主动读取个人浏览器的密码和 Cookie。
- 需要使用已有浏览器登录状态时，必须在当前任务中明确提出。
- 上传文件、发送消息、发布内容和提交表单前需要确认。
- 软件不会在用户没有发送任务时主动操作电脑。

## 十二、检查和安装更新

### 手动检查

1. 点击左下角“设置”。
2. 在“软件更新”中查看当前版本。
3. 点击“检查更新”。
4. 有新版本时，查看版本号、发布时间、大小、标题和更新内容。
5. 点击“立即更新”。
6. 等待后台下载、校验和安装。
7. 安装完成后软件会自动重新打开。

“自动检查更新”开启后，软件会在启动时和运行期间检查新版本。下载中断后可再次更新，已校验的下载缓存会尽量复用。

更新期间不要强制关机。更新完成后，历史会话和本地数据仍使用原来的数据目录。

## 十三、本地数据位置

```text
程序文件：C:\Program Files\先马·AI Studio
公共配置：C:\ProgramData\XianmaAIStudio
数据路由：%APPDATA%\XianmaAIStudio\user-data-route.json
当前用户数据：%APPDATA%\xianma-ai-studio
旧版兼容数据：%APPDATA%\xianma-centaur-desktop
```

注意：

- 普通使用时不要修改这些目录。
- 卸载程序不会主动删除这些用户数据。
- 不要使用第三方清理工具删除相关 AppData 或 ProgramData。
- 当前数据保存在本机，不会自动同步到另一台电脑。

## 十四、常见问题

### 1. 安装时一直不动

1. 先等待当前步骤完成，大安装包解压可能需要一些时间。
2. 检查系统盘剩余空间和杀毒软件拦截提示。
3. 可以点击安装器“取消”；安装器会回滚未完成内容。
4. 仍无法完成时，重新启动电脑后再次安装。

### 2. 安装后看不到历史对话

1. 确认登录的是原来的钉钉账号。
2. 不要继续清理或覆盖 AppData。
3. 检查旧版数据目录是否仍存在。
4. 联系技术人员处理数据路由，不要自行移动目录。

### 3. 无法扫码登录

1. 检查电脑网络和手机钉钉网络。
2. 关闭登录窗口后重新点击“打开扫码登录”。
3. 确认使用公司允许的钉钉账号。
4. 二维码过期时刷新后重新扫描。

### 4. 模型回复失败或很慢

1. 保持网络连接，复杂文档和图片任务通常比普通问答更慢。
2. 点击停止按钮后重新发送更明确的要求。
3. 使用“自动选择”或切换到适合任务的模型。
4. 大文件处理时保持源文件路径不变。

### 5. 图片没有生成

1. 选择 `gpt-image-2` 或“自动选择”。
2. 写清楚画面、尺寸、风格和用途。
3. 等待图片模型完成，不要重复快速点击发送。

### 6. 技能安装失败

1. 确认技能是 `.md`、`.markdown`、`.zip` 或包含 `SKILL.md` 的文件夹。
2. 确认 ZIP 未损坏，技能来源可访问。
3. 在线技能加载较慢时检查网络后重试。
4. 不要删除技能包内的说明文件和依赖资源。

### 7. 文件无法打开或保存

1. 检查绝对路径是否正确。
2. 确认当前 Windows 账号对目标目录有权限。
3. 检查文件是否被其他程序占用。
4. 换到桌面或文档目录重试。

### 8. 检查更新失败

1. 检查网络是否能访问公司更新服务。
2. 稍后再次点击“检查更新”。
3. 不要手动修改软件内部版本或更新通道。
4. 长时间无法更新时，使用公司提供的新安装包覆盖安装。

## 十五、使用注意事项

- 只从公司指定渠道获取安装包和技能。
- 不要向对话中输入密码、模型密钥、钉钉密钥或其他凭证。
- 删除、覆盖、命令执行和外发操作前必须认真核对确认弹窗。
- 重要文件操作前建议自行保留备份。
- 不要手动修改公共配置和用户数据目录。
- 软件不提供远程桌面、后台监控、屏幕采集或无人值守远控。
- 当前仅支持 Windows，macOS 版本后续单独开发。
