## 本版能力

- 多会话 AI 对话、流式输出、并行请求和停止生成。
- 前端真实模型切换和自动路由。
- 所有会话默认具备文件、文档、命令和浏览器能力。
- 支持当前 Windows 账号可访问的不同磁盘和绝对路径。
- 支持创建及处理 Word、PPT、Excel、PDF、图片、代码和网页。
- 支持应用内文件卡、预览、复制、下载和 HTML 网页预览。
- 支持本地与在线技能安装、后台执行和按会话选择。
- 支持钉钉登录和本机多用户数据隔离。
- 支持 `stable-v2` 自动更新。

## 权限边界

所有钉钉用户默认可使用本机操作能力，不设置管理员授权、白名单、首次授权或功能开关。

软件只能使用当前 Windows 账号已有权限，不能绕过文件权限或 UAC。

以下操作必须二次确认：

```text
覆盖已有文件
删除文件或目录
移动或复制并替换已有文件
运行任意 Shell、PowerShell 或 CMD 命令
安装或卸载软件
修改注册表、服务、启动项或计划任务
上传文件、发送消息、发布内容或提交表单
```

软件不提供管理员远控、屏幕采集、后台监控或无人值守控制。

## 卸载旧版

1. 正常退出先马·AI Studio。
2. 打开 Windows“设置 → 应用 → 已安装的应用”。
3. 找到旧版并点击“卸载”。
4. 不使用第三方卸载清理工具。
5. 不删除任何先马 AppData 或 ProgramData 目录。

卸载器只删除安装目录中的程序文件，保留会话、技能、附件、登录状态和公共配置。

## 安装统一版本

1. 双击 `先马·AI Studio Setup 1.0.2 统一版本重装版.exe`。
2. Windows 弹出 UAC 时点击“是”。
3. 保持默认安装目录。
4. 根据需要保留桌面快捷方式。
5. 完成后启动软件。
6. 使用原钉钉用户登录并检查历史内容。

安装器允许取消并自动回滚未完成安装。首次使用完整能力时会准备内置运行时，界面显示真实进度并允许取消。

## 数据恢复验收

在旧版卸载前，为两个钉钉用户分别准备：

```text
至少两个会话
至少一个已安装技能
至少一张图片
至少一个生成文件
```

重装后验证：

1. 两个用户都能登录。
2. 每个用户只看到自己的会话和技能。
3. 历史图片、附件和文件卡仍可打开。
4. 新会话可继续创建和修改文件。
5. `user-data-route.json` 指向原有完整数据目录。

若数据未出现，立即停止继续操作，保留 `%APPDATA%` 原目录用于恢复。

## 本机能力验收

普通操作：

- 在桌面、`C:\` 和 `D:\` 创建并读取测试文件。
- 创建 Word、PPT、Excel、PDF 和 HTML。
- 打开生成文件和应用内网页预览。
- 打开可见自动化浏览器并完成点击、输入和下载。
- 在不同会话分别执行任务，确认能力不受会话限制。

危险操作：

- 覆盖、删除和命令执行必须出现确认弹窗。
- 点击取消后目标文件和系统状态不变。
- 点击允许后只执行弹窗展示的本次操作。
- 停止会话、关闭窗口或确认超时后自动拒绝。

## 更新验收

1. 确认 `1.0.2` 只检查 `stable-v2`。
2. 确认不会显示旧 `stable` 通道版本。
3. 发布测试版 `1.0.3 / 1.0.3 / stable-v2`。
4. 在设置页点击“检查更新”。
5. 查看版本号、标题和更新内容。
6. 完成自动下载、覆盖安装和自动重启。
7. 验证更新后历史数据完整。

## 发布顺序

1. 完成代码和测试。
2. 构建统一版本并计算 SHA-256。
3. 在一台独立测试电脑卸载旧版并安装新版。
4. 验证数据和本机操作能力。
5. 部署更新服务代码。
6. 在后台发布 `stable-v2 / 1.0.2`。
7. 用 `1.0.3 / 1.0.3` 验证真实自动更新。
8. 测试通过后通知全员卸载旧版并安装统一版本。
9. 全员迁移完成后再撤回旧 `stable` 版本。
