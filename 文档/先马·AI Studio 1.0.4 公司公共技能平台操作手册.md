# 先马·AI Studio 1.0.4 公司公共技能平台操作手册

## 1. 版本信息

```text
产品：先马·AI Studio
客户端版本：1.0.4
内部版本：1.0.4
更新通道：stable-v2
适用系统：Windows 10 / Windows 11 64 位
```

## 2. 功能入口

登录后打开左侧“技能”，公司公共技能区包含：

- 创建公司技能：使用表单生成标准技能包。
- 提交技能审核：上传 Markdown、ZIP 或标准技能文件夹。
- 公司技能库：查看并安装已审核技能。
- 我的提交：查看审核状态和驳回原因。

本地技能和外部在线技能入口保持不变。

## 3. 创建公司技能

1. 打开“技能 > 创建公司技能”。
2. 填写技能名称、技能标识、版本、分类、说明和对话引导语。
3. 填写适用场景、输入要求、输出要求、执行流程、边界、异常处理和使用示例。
4. 填写支持的输入、输出格式、权限和依赖。
5. 按需添加模板、图片、脚本或参考资料。
6. 点击“生成并预览”进入提交页，或点击“下载技能包”保存 ZIP。

技能标识要求：

```text
只使用小写字母、数字和连字符
最长 64 个字符
示例：project-weekly-report
```

版本要求：

```text
使用 1.0.0、1.0.1、2.0.0 这类语义化版本
新审核版本必须高于已发布版本
```

草稿按当前钉钉用户保存在本机。切换钉钉用户后，草稿互不混用。

## 4. 使用标准模板

1. 在创建页或提交页点击“下载标准模板”。
2. 解压 ZIP。
3. 修改 `SKILL.md` 和 `skill.json`。
4. 保持以下目录结构：

```text
skill-name/
├── SKILL.md
├── skill.json
├── scripts/       # 可选
├── references/    # 可选
└── assets/        # 可选
```

5. 修改完成后重新压缩，或直接选择技能文件夹提交。

不要在技能包中填写 API Key、密码、Token、Secret、Cookie 或其他明文凭证。

## 5. 导入现有 Markdown

1. 打开“技能 > 提交技能审核”。
2. 点击“选择文件”，选择 `.md` 或 `.markdown`。
3. 页面会显示缺失的标准内容。
4. 点击“导入表单向导修正”。
5. 补齐必填项后重新生成标准 ZIP。
6. 返回提交页进行本地校验和提交。

不完整 ZIP 中只要存在安全可读取的 `SKILL.md`，也可导入向导补全。包含越界路径、符号链接、损坏压缩内容或压缩炸弹的包会直接拒绝。

## 6. 提交审核

支持：

```text
.md
.markdown
.zip
包含 SKILL.md 与 skill.json 的文件夹
```

提交流程：

1. 选择文件或文件夹。
2. 查看技能名称、版本、说明、输入类型和文件清单。
3. 本地校验通过后点击“提交审核”。
4. 上传在后台继续，可以切换到其他页面。
5. 上传完成后会显示通知。

提交身份来自当前钉钉登录信息，不能由技能包修改。

状态说明：

```text
待审核：等待管理员处理
已通过：已进入公司技能库
已驳回：根据驳回原因修改后提高版本并重新提交
已下架：管理员已停止该技能继续使用
```

## 7. 管理员审核

1. 打开现有更新管理后台。
2. 输入服务器当前配置的后台管理密码。
3. 打开“技能审核”。
4. 选择待审核记录。
5. 检查提交人、部门、版本、说明、文件树、SHA-256、风险项和文本预览。
6. 需要时下载原始包离线检查。
7. 选择批准或填写原因后驳回。

高风险技能批准前必须勾选风险确认。审核员只能批准、驳回或下架，不能静默修改用户提交内容。

## 8. 安装和使用公司技能

1. 打开“技能 > 公司技能库”。
2. 找到需要的技能并点击“安装”。
3. 安装完成后，该技能出现在当前钉钉用户的技能列表和对话技能选择器中。
4. 在目标对话中选择技能后再发送任务。

公司技能不会自动安装。已安装技能会在客户端启动时和每 15 分钟检查新审核版本，并自动更新。

下载内容会校验 SHA-256 和 Ed25519 签名。校验失败时保留旧版本。技能被下架后，客户端同步时会停用并隔离已安装副本。

## 9. 技能生成文档排版

- 技能返回的 YAML 信息会转换为正式标题和“基本信息”表格，不会直接显示技术字段。
- Markdown 标题、加粗、列表和表格会转换为文档原生样式，不会保留 `#`、`**`、代码围栏等标记。
- Word 文档统一使用微软雅黑、规范字号、行距、页边距、章节层级和表格样式。
- PPT、Excel、PDF、OpenDocument、RTF、HTML、TXT、Markdown、JSON、XML、CSV 和 ZIP 使用同一套内容清理规则。
- TXT 和 Markdown 文件首行使用正式文档标题，不使用内部技能标识作为标题。

## 10. 使用统计

后台只展示公司技能的匿名聚合数据：

- 调用次数。
- 成功次数。
- 失败次数。
- 用户取消次数。
- 成功率。
- 最后调用时间。
- 近 7 天和近 30 天趋势。

不保存使用人、钉钉 ID、姓名、部门、设备、IP、提示词、附件、结果、文件路径或错误正文。

## 11. 常见问题

### 公司技能页面显示服务不可用

确认服务端已部署 1.0.4 兼容代码，当前钉钉账号已通过 MAPMS 鉴权，并重新登录客户端。

### Markdown 不能直接提交

单个 Markdown 缺少 `skill.json`。先导入表单向导，补齐信息并生成标准 ZIP。

### 审核通过后看不到技能

在公司技能库点击“刷新”，确认提交状态为“已通过”。仍不可见时检查服务端审核记录和公司技能目录。

### 新版本没有自动更新

确认已安装的是公司技能，最新版本已审核通过，客户端网络正常。退出并重新打开客户端会立即触发一次同步。

### 下架后本机仍看到技能

等待下一次同步，或重新启动客户端。同步后技能会被停用并移入隔离目录。

### 点击下载文档提示文件正在使用

客户端会先自动重试。如果下载目录中的同名文件正被 Word 或其他程序占用，会自动另存为 `文件名 (2).docx` 并提示实际保存名称。若生成目录中的源文件也被外部程序独占，请关闭该文件后重试。

## 12. 数据与安全

- 公司技能安装到当前钉钉用户的私有技能目录。
- 不同钉钉用户的草稿、提交、技能和会话相互隔离。
- 脚本、网络、Shell、程序和环境变量依赖会标记风险。
- 运行时危险文件或系统操作仍需用户二次确认。
- 服务端和客户端均不设置业务级附件大小限制；超大文件仍受磁盘空间和 2GB 基础设施安全上限约束。
