## 本版重点

- 后台用户统计优先展示钉钉昵称，真实姓名不再作为列表标题。
- 任务趋势改为任务数、成功数、失败数三条折线，并补齐空时间段，少量数据也保持连续横轴。
- 失败数只统计明确返回 HTTP 404 的任务；500、超时、取消、网络或文件错误均不计失败。
- 服务端分类和标签支持编辑、启用、停用、删除，并同步到客户端技能页。
- 新增/编辑弹窗点击 X 或取消时直接关闭，不触发必填校验。
- 用户详情改为右侧全高抽屉，展示任务、成功率、技能调用和最近模块。
- 只有版本发布页验证管理员密码，其他 V1.1 管理页面无需密码。
- 技能库三页签、搜索、12 个分类、标签和三列技能卡。
- 公司技能创建、提交、撤回、审核、发布、安装、自动升级、下架和匿名统计。
- 东哥会议模型固定为内置技能第一项，保持原技能 ID 和完整 V4.0 规则。
- 浏览器能力恢复为 `1.3.0.3` 原执行路径，不增加 V1.1 浏览器任务卡或暂停、继续、停止包装层。
- 原浏览器插件和完整代理能力保留，支持打开、读取、点击、输入、选择、滚动、上传、等待和下载。
- 浏览器访问和关键操作匿名反馈到测试后台，不改变实际模型与工具路由。
- 历史会话、技能、附件、文件和多钉钉用户数据继续沿用原数据路由。

## 安装步骤

1. 完全退出正在运行的先马·AI Studio。
2. 建议先备份 `%APPDATA%\XianmaAIStudio`、`%APPDATA%\xianma-ai-studio` 和 `%APPDATA%\xianma-centaur-desktop`。
3. 直接双击测试安装包覆盖安装，不需要先卸载旧版。
4. Windows 弹出 UAC 时点击“是”，保持原安装目录。
5. 启动后使用原钉钉账号登录。
6. 先检查最近会话、技能和历史文件，再开始新任务。

如必须卸载旧版，不要使用第三方深度清理工具，也不要删除 AppData、ProgramData 或 `user-data-route.json`。

## 验收清单

### 历史数据

- 最近会话仍存在，原消息可以打开。
- 不同钉钉用户只看到各自数据。
- 已安装技能、图片、附件和生成文件仍可访问。
- 新会话可以继续生成和修改文件。

### 技能库

- 页面显示“全部技能 / 我的技能 / 企业技能”。
- 分类可切换，搜索和标签过滤有效。
- 东哥会议模型是第一张内置技能卡，点击后六项输出重点不可取消。
- 创建标准技能的完整示例可填入、修改、预览和校验。
- 提交后可在“我的提交”查看状态并在待审核时撤回。
- 管理后台可以审核、发布、下架和重新发布。
- 已发布企业技能可安装、执行和自动更新。

### 浏览器

- 对话中要求打开网页时进入与 `1.3.0.3` 相同的完整代理路径。
- 不显示 V1.1 浏览器任务卡，不出现暂停、继续或停止浏览器任务按钮。
- 原有普通点击、输入、选择、滚动、上传、等待和下载能力可执行。
- 包内 `browser.enabled`、浏览器插件和 browser 工具白名单保持启用。

### 数据迁移与更新

- 设置页版本显示 `1.4.0`。
- 测试包检查 `v11-preview`，不会读取正式 `stable-v2` 版本。
- 覆盖安装后历史数据不变。
- 不在后台上传此安装包，不创建正式更新记录。
