# 钉钉免登录接入说明

## 目标

- 仅允许钉钉账号登录，不提供账号密码入口。
- 首次完成 OAuth 授权，后续在本机自动恢复登录。
- 使用钉钉 `unionId` 作为稳定用户 ID。
- 会话、记忆、任务结果和工作区按用户 ID 隔离保存在本机。
- 访问令牌和刷新令牌只存在 Electron 主进程，并使用系统安全存储加密落盘。

## 已实现流程

1. 应用启动后读取本机加密会话。
2. 访问令牌剩余时间不足 5 分钟时，使用 `refreshToken` 自动续期。
3. 无可用会话时显示“使用钉钉登录”。
4. 点击登录后启动本机回调服务，在应用内打开官方二维码登录窗口；账号登录仍由钉钉官方页面处理。
5. 回调同时兼容 `authCode` 和 `code` 参数，并校验随机 `state`。
6. 使用授权码获取用户访问令牌。
7. 使用 `x-acs-dingtalk-access-token` 请求当前用户通讯录个人信息。
8. 校验 `corpId`，保存用户身份和加密会话。
9. 退出登录时删除当前用户的本机登录凭证，并清除钉钉授权 Cookie、站点存储和缓存，但不删除该用户的本地工作数据。

访问令牌有效期为 2 小时，刷新令牌有效期为 30 天。超过 30 天未使用或授权失效时，需要重新登录。

## 配置文件

安装后配置文件位于：

`C:\ProgramData\XianmaCentaur\dingtalk-config.json`

安装器会写入公开参数，`clientSecret` 默认留空并使用随包加密凭据。此文件主要用于管理员覆盖参数，不需要普通用户手工修改。

示例：

```json
{
  "clientId": "填写 AppKey",
  "clientSecret": "填写 AppSecret",
  "corpId": "填写企业 CorpId",
  "redirectUri": "http://127.0.0.1:17891/dingtalk/callback",
  "scope": "openid corpid",
  "prompt": "consent",
  "loginMode": "embedded",
  "embeddedQr": true,
  "useSystemBrowser": false,
  "enforceCorpId": true,
  "authUrl": "https://login.dingtalk.com/oauth2/auth",
  "tokenUrl": "https://api.dingtalk.com/v1.0/oauth2/userAccessToken",
  "userInfoUrl": "https://api.dingtalk.com/v1.0/contact/users/me"
}
```

修改后必须完全退出所有“先马智能体”进程再重新启动。

也可通过环境变量提供敏感值：

- `XIANMA_DINGTALK_CLIENT_ID`
- `XIANMA_DINGTALK_CLIENT_SECRET`
- `XIANMA_DINGTALK_CORP_ID`
- `XIANMA_DINGTALK_CONFIG`

## 本地数据隔离

渲染层用户数据键：

`centaur.desktop.chat.v3:<unionId>`

用户文件目录：

`%APPDATA%\xianma-centaur-desktop\users\<unionId>\workspace`

任务和结果目录同样位于对应用户目录下。切换钉钉用户后，不加载前一用户的会话、记忆、附件、任务或工作区。渲染层不再额外保存姓名、头像、企业 ID 或令牌等登录会话快照。

## 正式发布安全要求

当前单 EXE 试点包将 `AppSecret` 拆分加密后随包携带，普通用户界面和配置文件中不显示明文。但桌面端必须具备解密并调用钉钉接口的能力，因此有本机管理权限和逆向能力的用户仍可能提取密钥；这不等同于服务端密钥安全。

正式全员分发建议增加公司认证代理：

1. AppSecret 只保存在公司服务器。
2. 桌面端跳转公司认证入口。
3. 公司服务完成钉钉授权码换票和企业校验。
4. 公司服务向桌面端返回短期、一次性的登录票据。
5. 桌面端只保存公司会话令牌，不保存 AppSecret 和钉钉 refreshToken。

如果钉钉开发后台不接受 `127.0.0.1` 回调地址，则公司 HTTPS 认证代理是必选项，需要额外提供可公网访问的 HTTPS 域名和部署环境。

## 验收清单

- 未配置时，应用明确提示管理员配置，不允许账号密码登录。
- 用户 A 首次授权后进入工作台，重启应用可自动恢复。
- 用户 A 退出后，用户 B 登录只能看到用户 B 的空白或既有数据。
- 再次登录用户 A，能够恢复用户 A 的历史会话和工作区。
- 非指定 `corpId` 的账号被拒绝。
- 令牌过期前后均能自动刷新，无需再次输入账号密码。
- 删除或篡改加密会话后，应用回到钉钉登录页。
- 日志、界面和渲染进程中均不出现 AppSecret、accessToken 或 refreshToken。
