# 先马·AI Studio 1.4.0 服务端手工部署说明

## 交付边界

- 本包用于本地检查和后续手工部署。
- 本次构建没有连接、上传或修改生产服务器。
- 客户端安装包没有发布到更新通道。
- 试用通过后再由管理员手工部署。

## 包内文件

```text
server.js             更新、统计、MAPMS 与模型路由服务
company-skills.js     公司技能提交、审核、发布和匿名统计
public/admin.html     管理后台页面
docker-compose.yml    Docker 启动配置
.env.example          环境变量模板，不含真实密钥
手工部署说明.md        本文档
```

## 部署前备份

假设服务目录为 `/opt/xianma-update-service`，必须先备份：

```text
/opt/xianma-update-service/data
/opt/xianma-update-service/secrets
/opt/xianma-update-service/.env
/opt/xianma-update-service/docker-compose.yml
```

不要覆盖或重新生成 `secrets/update-signing-private.pem`。客户端使用对应公钥校验更新包和公司技能包。

## 配置

1. 参考 `.env.example` 补齐服务器原有 `.env`。
2. 保持 `ENABLE_COMPANY_SKILL_PLATFORM=1`。
3. `UPDATE_ADMIN_TOKEN` 使用后台管理密码，但不要写进源码或安装包。
4. 填写 MAPMS、钉钉和模型服务的真实配置。
5. `ADMIN_FRAME_ANCESTORS` 只填写允许嵌入后台的受控网站来源。

## 手工部署

只覆盖代码和页面，不覆盖 `data/`、`secrets/`、`.env`：

```bash
cd /opt/xianma-update-service
docker compose config
docker compose up -d --force-recreate
docker compose ps
docker compose logs --tail=100
```

`docker-compose.yml` 必须包含：

```text
./company-skills.js:/app/company-skills.js:ro
ENABLE_COMPANY_SKILL_PLATFORM=1
```

## 部署后验收

1. 管理后台可打开“软件使用统计”“技能审核”“版本发布”。
2. 测试钉钉用户可以创建并提交技能。
3. 管理员可以预览、批准、驳回和下架技能。
4. 审核通过的技能可在客户端公司技能库中安装。
5. 已安装公司技能新版本可自动同步。
6. 下架后客户端同步时停用本地副本。
7. 匿名统计仅包含调用、成功、失败、取消次数，不包含用户身份、提示词、附件和结果。
8. 原更新发布、MAPMS 鉴权、用户统计和模型路由仍正常。

## 回退

1. 停止新容器。
2. 恢复部署前备份的代码和 `docker-compose.yml`。
3. 保留最新 `data/`，不要直接删除技能提交和审核数据。
4. 恢复后重新启动并检查日志。
