## 接入要求（契约 2.4 / 16.1 摘要）

- 生产不得硬编码个人电脑 `.codex/skills` 目录，也不得运行其中面向钉钉或知识库写入的外部脚本；
- 资源包必须受控、可部署、可回退；每次升级需与输入输出 schema 兼容性一起评审，无法兼容时保留上一可用版本并禁止自动切换；
- AI Studio 模式只加载需求分析所需规则和引用；钉钉建 REQ、需求池写入、通知和个人工作区路径不得成为 AI Studio 运行依赖；
- 进入联调前需形成版本化开发资产：本包 + 接入契约 + V2.1.0 增量 PRD/原型说明 + `AI_CAPABILITIES.md` 字段规范 + SA-01~SA-16 脱敏评测用例。
